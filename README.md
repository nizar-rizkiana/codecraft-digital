# CodeCraft Digital — Website Profile Company

Website Profile Company modern untuk brand teknologi **CodeCraft Digital** (*Creative Technology Community & Digital Studio*).

## Stack Teknologi
- **HTML5** (Semantic Markup)
- **CSS3** (CSS Variables, Flexbox, Custom Grid Pattern & Glow Effects)
- **Bootstrap 5.3.2** (Layout & Framework)
- **Bootstrap Icons 1.11.2** (Vector Icons)
- **Vanilla JavaScript** (IntersectionObserver Animations, Smooth Scroll, Dynamic Portfolio Filter)

## Fitur Utama
1. **Modern Visual Identity**: Integrasi CSS Variables dengan skema warna khas Primary Blue `#1150F8` & Cyan `#2EBEFF`.
2. **Hero Floating Ecosystem**: Ilustrasi visual floating technology card menggantikan stock photo konvensional.
3. **Interactive Portfolio Filter**: Filter project menggunakan Vanilla JavaScript.
4. **Custom Dark Glassmorphism**: Tampilan futuristik pada section Digital Services.
5. **Timeline Horizontal/Vertical**: Alur kerja dari ide hingga produk yang responsif untuk seluler.
6. **Smooth Animations**: Efek *fade-up on scroll* tanpa library tambahan.

## Cara Menjalankan Project
1. Clone atau download repository ini.
2. Buka file `index.html` langsung di browser web favorit Anda.
